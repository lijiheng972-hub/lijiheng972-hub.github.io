07.2026 — now GUI agents Evaluation

Are multimodal skills necessary for GUI agents?

Independent research

When a GUI agent gets better with "skills", how much of the gain is the skill, and how much is the prompt around it?

The no-skill baseline and the skill condition in OSWorld were not equivalent at the prompt level. After splitting the prompt into switchable modules, most of the reported gain came from scaffolding, not from skill knowledge.

≈58%of the gain is prompt scaffolding
360tasks in the ablation
4scaffolds made switchable
Details
  • Refactored four prompt scaffolds into independent switches and ran a 360-task ablation on OSWorld to separate scaffolding from skill knowledge.
  • Traced failures to concrete mechanisms: output-parse errors, premature self-termination, and the execution harness. A large share of tasks fail under every condition, which points at the agent–environment interface more than at visual perception.
  • Audited the text-only condition in code: it only injects SKILL.md, and some visual cues refer to a reference image instead of the runtime UI. So the original comparison cannot rule multimodal skills in or out.
  • Now: Skill Verbalization, which turns visual references into text under a five-type schema (each type ablatable), plus an offline discriminability check with hard negatives. The score is meant as a routing signal for when to call the multimodal path. Per-task flip rate is used to measure how stable a conclusion is.
  • Infrastructure: reproducible OSWorld pipeline on VMware Fusion with Qwen3-VL-8B behind an OpenAI-compatible API.

03 — 07.2026 World models Inverse dynamics

DynamiX and action-controllable world models from gameplay video

Research intern · data engine owner

Can diverse, pseudo-labeled gameplay teach a video model what an action does to the world, rather than what it looks like?

DynamiX infers the controls behind a gameplay video across many games. I built GameMotion-A, the data engine that turns raw YouTube gameplay into training clips for it. The follow-up uses DynamiX's pseudo-labels to train an action-conditioned video model and tests whether actions have consistent consequences: undo an action and see if the world comes back, look away and look back.

≈5,800 hYouTube gameplay processed
Qwen3-VL-30B-A3Bmulti-stage clip filter
CogVideoX-2Bvideo backbone
Details
  • Data engine: frame-level automated quality checks, and a multi-stage feedback-and-filter pipeline on Qwen3-VL with explicit rules for viewpoint, streamer facecam, danmaku comments, scene transitions and UI/HUD.
  • Labeling pipeline: center crop, resample to 15 FPS, cut detection, UI removal with GameCleaner, pseudo-labels from DynamiX. Frame alignment uses a 12-frame window with stride 8, keeping the middle 8 frames; the full action distribution is kept so training can weight by confidence.
  • Model: CogVideoX-2B image-to-video, actions injected through AdaLN. Actions are pooled per type (sum for camera yaw/pitch, mean for held keys, max for presses) to match the 3D VAE's 4× temporal compression. History frames are noised during training so long autoregressive rollouts do not drift.
  • Evaluation: closed-loop reversibility, occlusion-and-reveal consistency, compositional action generalization, zero-shot transfer to unseen games. Geometry is scored with RAFT optical flow, so the model is not judged by the same IDM that labeled its data.

01 — 07.2026 HUST LLM for code

Detecting and reducing hallucination in LLM code summaries

Undergraduate research project · Huazhong University of Science and Technology

A benchmark, a detector and a decoding strategy for summaries that describe code the function does not contain.

17% → 97%trigger rate with AST predicate negation
F1 0.95detector on Qwen2.5-Coder-7B
66% → 59%hallucination rate, DeepSeek-Coder-6.7B
Details
  • Hallu-Eval: 800 human-annotated code–summary pairs. Adversarial tests negate AST predicates to stress the model.
  • Hallu-Det: two-stage rule-augmented evaluator (entity checks, then synonym-mutation refinement). Beats SelfCheckGPT.
  • Hallu-Shield: MDP-style decoding where a trained value model scores candidates at inference time; 71.5% win rate in human evaluation.
